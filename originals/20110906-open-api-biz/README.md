## 재수집

```bash
npm install
node scripts/scrape.mjs
```

실제 Chrome 창이 열립니다. 스크립트 상단 `PROFILE` 경로의 전용 프로필에 네이버 쿠키가
남아 있으면 자동으로 진행되고, 없으면 로그인 창이 다시 열립니다(수동 로그인 1회 필요).
기존 markdown은 덮어쓰고, 이미 받은 첨부파일은 건너뜁니다.

  내려받지 못했고, 본문에 원격 URL 그대로 남아 있습니다.
- 댓글은 수집 대상에 포함하지 않았습니다.
- 카페북 게시판에는 하위 페이지를 묶는 용도의 빈 목차 페이지가 있으며, 목차에 `(본문 없음)`으로 표시했습니다.
