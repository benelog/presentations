## 빌드 / 배포
[Slidev](https://sli.dev/) 마크다운으로 작성하고 GitHub Pages 로 배포.

```bash
npm install                              # 최초 1회
npm run build                            # dist/ 에 전체 빌드
npm run dev -- YYYYMMDD-slug/slides.md   # 라이브 미리보기 서버
```

main 에 push 하면 GitHub Actions 가 자동으로 빌드 후 GitHub Pages로 배포됨.
빌드는 증분 방식: 소스가 바뀐 발표만 다시 빌드한다 (`scripts/build.sh` 가 `dist/<발표>/.build-hash` 로 판단).

자세한 작성 규칙·파이프라인은 [`build_slides.md`](build_slides.md) 참고.

## 화면 잘림 검사

콘텐츠가 슬라이드 캔버스(1280×720)를 넘어 하단이 잘리는 슬라이드를 자동 검출한다.
슬라이드를 한 장씩 실제로 렌더링해서 측정하므로 느리다(29장짜리 덱 1개에 약 11초, 전체 덱은 수 분).
그래서 빌드 과정에는 포함하지 않았고, 필요할 때만 수동으로 실행한다.

```bash
npm run build                                    # 먼저 dist/ 생성
npm run check                                    # 전체 덱 검사 (잘림 있으면 exit code 1)
npm run check -- 20140608-spring-anti-patterns   # 특정 덱만 검사
```

잘리는 슬라이드는 텍스트/리스트면 페이지 분할, 이미지가 원인이면 이미지 height 축소로 수정한다.
